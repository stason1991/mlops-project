## Инструкции по запуску компонентов

Все компоненты системы полностью настроены на совместную работу. Ниже описан пошаговый запуск каждого этапа.

### 1. Подготовка окружения и скачивание данных
Перед запуском установите библиотеки и скачайте актуальные файлы из облака:
```bash
# Установка всех зависимостей проекта
pip install -r requirements.txt

# Скачивание датасета и модели из MinIO через DVC
dvc pull
```

### 2. Запуск экспериментов (MLflow)
Чтобы заново запустить сетку из 100 экспериментов и залогировать их в локальный сервер:
1. Запустите сервер MLflow в отдельном терминале:
   ```bash
   mlflow server --host 127.0.0.1 --port 5000
   ```
2. Запустите скрипт проведения экспериментов:
   ```bash
   python experiments.py
   ```
После завершения лучшая модель автоматически зарегистрируется в реестре MLflow Model Registry.

### 3. Запуск автоматического обучения (Airflow DAG)
Для настройки регулярного ежедневного переобучения модели:
1. Поместите файл `wine_pipeline_dag.py` и `config.py` в вашу системную папку Airflow .
2. Запустите веб-интерфейс Airflow и включите DAG с именем `wine_production_pipeline`.
3. DAG будет запускаться автоматически каждую полночь. Он заново скачает данные через DVC API, обучит модель со случайным лесом по параметрам из `config.py` и сделает `dvc push` новой версии в MinIO.

### 4. Запуск и проверка API сервера (FastAPI)
Веб-сервер работает в двух режимах: синхронизация и инференс.

*   **Режим синхронизации с MLflow:**
    Если вам нужно выкачать самую последнюю зарегистрированную модель из MLflow и обновить её указатель в DVC, запустите:
    ```bash
    python src/api/api.py --sync
    ```
*   **Обычный режим работы сервера:**
    Для старта веб-сервера на локальной машине запустите команду:
    ```bash
    python src/api/api.py
    ```
    После запуска перейдите в браузере по адресу `http://127.0.0`. Интерактивная документация Swagger UI позволит протестировать три обязательных эндпоинта: `/predict` (с защитой от отрицательных чисел), `/healthcheck` и `/model-info`.

# Эксперименты по прогнозированию качества вина (Wine Quality Regression)

В данном проекте решена задача регрессии по предсказанию экспертной оценки качества красного вина на основе его физико-химических свойств. Проведено автоматизированное исследование гиперпараметров (Grid Search) для двух семейств моделей с полным трекингом в системе **MLflow**.

---

## Описание моделей и гиперпараметров

Для обеспечения воспроизводимости во всех экспериментах зафиксирован единый `random_state = 42`. Перед подачей в модели данные автоматически масштабировались с помощью `StandardScaler` внутри сквозного пайплайна (`Pipeline`), исключая утечку данных.

### 1. Lasso Регрессия (L1-регуляризованная линейная модель)
Линейная модель, которая штрафует абсолютные значения весов признаков, зануляя наименее важные из них.
*   **`alpha` (10 вариантов от 0.0001 до 2.0):** Коэффициент силы регуляризации. Чем он выше, тем проще модель и тем больше признаков исключается.
*   **`max_iter` (5 вариантов от 500 до 3000):** Максимальное количество итераций для сходимости алгоритма координатного спуска.

### 2. Random Forest Regressor (Случайный лес)
Ансамбль независимых деревьев решений, усредняющий их предсказания.
*   **`n_estimators` ([50, 100, 150, 200, 300]):** Количество деревьев в лесу. Большее количество снижает разброс предсказаний.
*   **`max_depth` ([5, 8, 10, 12, 15]):** Предельная глубина каждого дерева, контролирующая сложность улавливаемых зависимостей.
*   **`min_samples_split` ([2, 5]):** Минимальное число объектов в узле, необходимое для совершения очередного ветвления.

## Обоснование выбора лучшей модели

По результатам комплексного многокритериального отбора лучшей признана модель **Random Forest Regressor** (Запуск: `RF_Run_42`).

### Причины выбора:
1. **Абсолютное превосходство по метрикам:** Случайный лес показал наивысший коэффициент детерминации $R^2 = 0.5377$. Модель успешно объясняет около **54% дисперсии** целевой переменной. Линейная модель Lasso уступила победителю более чем на 13 процентных пунктов ($R^2 = 0.4011$).
2. **Минимальная ошибка:** Метрика **MAE = 0.4237** указывает на то, что в среднем предсказание модели ошибается менее чем на полбалла по шкале качества вина. Значение **MSE = 0.3021** подтверждает отсутствие критически крупных и грубых ошибок в предсказаниях.
3. **Характер данных:** Физико-химические параметры вина (кислотность, уровень сахара, сульфаты, алкоголь) имеют сложные, нелинейные и зацепленные друг за друга связи с финальной оценкой. Линейная регрессия Lasso не способна их смоделировать, в то время как глубокие деревья решений (`max_depth: 15`) успешно справились с этой задачей.
4. **Защита от переобучения:** Использование `min_samples_split: 2` позволило деревьям максимально точно настроиться на детальные закономерности, а ансамблирование (комбинация из 100 деревьев) компенсировало их склонность к переобучению, обеспечив высокую обобщающую способность на тестовых данных.
